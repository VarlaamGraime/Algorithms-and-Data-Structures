Лабораторная работа №3

1. Стоимость конфет

По цене за 1 кг найдите стоимость конфет для 0,1 кг, 0,2 кг и так далее до 1 кг.

2. Произведение сомножителей

Для целого N > 0 найдите произведение 1,1 · 1,2 · 1,3 · … из N сомножителей.

3. Квадрат через сумму нечётных чисел

Найдите квадрат целого N > 0 по формуле N² = 1 + 3 + 5 + … + (2 · N − 1). После каждого слагаемого выведите текущую сумму.

4. Сумма степеней

Для вещественного A и целого N > 0 найдите сумму 1 + A + A² + … + Aⁿ за один цикл.

5. Знакочередующаяся сумма

Для вещественного A и целого N > 0 найдите сумму 1 − A + A² − A³ + … ± Aⁿ. Используйте один цикл без условного оператора для смены знака.

6. Повторение чисел

Выведите все целые числа от положительного A до B включительно, где A < B. Каждое число повторите столько раз, каково его значение. Например, 3 выводится трижды.

7. Незанятая часть отрезка

На отрезке длины A размещено максимальное число отрезков длины B без наложений, где A > B > 0. Найдите незанятую длину без умножения и деления.

8. Наименьшее K

Для целого N > 1 найдите наименьшее целое K, при котором сумма 1 + 2 + … + K достигнет N, и выведите эту сумму.

9. Рост вклада

Вклад 1000 рублей ежемесячно увеличивается на P процентов от текущей суммы, где 0 < P < 25. Найдите число месяцев K до превышения 1100 рублей и итоговую сумму S.

10. Наибольший общий делитель

Найдите наибольший общий делитель положительных целых A и B по алгоритму Евклида.
