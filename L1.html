Лабораторная работа №1

1. Стороны прямоугольника

По сторонам a и b найдите площадь S = a · b и периметр P = 2 · (a + b).

2. Длина окружности

По диаметру d найдите длину окружности L = π · d. Используйте π = 3,14.

3. Среднее арифметическое

Для чисел a и b вычислите (a + b) / 2.

4. Операции с квадратами

Найдите сумму, разность, произведение и частное квадратов двух ненулевых чисел.

5. Операции с модулями

Найдите сумму, разность, произведение и частное модулей двух ненулевых чисел.

6. Расстояние между точками

Найдите расстояние между точками (x₁, y₁) и (x₂, y₂).

7. Сумма длин отрезков

По координатам A, B и C на числовой оси найдите длины AC и BC и их сумму.

8. Произведение длин отрезков

Найдите произведение длин AC и BC. Точка C лежит между A и B.

9. Вершины прямоугольника

По двум противоположным вершинам найдите площадь и периметр. Стороны параллельны осям координат.

10. Вершины треугольника

По координатам трёх вершин найдите периметр и площадь треугольника.

11. Значение функции

Вычислите y = 3x⁶ − 6x² − 7 при заданном x.

12. Значение функции

Вычислите y = 4(x − 3)⁶ − 7(x − 3)³ + 2 при заданном x.
